# Bike Sales – Microsoft Excel Data Analytics Project
An end-to-end Microsoft Excel data analytics project featuring data cleaning, pivot tables, and an interactive Bike Sales Dashboard to uncover customer demographic trends and purchasing behavior.
Tools & Technologies

Microsoft Excel: Data analysis and dashboard development.

Power Query: Data cleaning and transformation.

Pivot Tables: Data summarization and analysis.

Pivot Charts: Data visualization.

Slicers: Interactive dashboard filtering.

Project Workflow

Data Preparation: Imported and explored the bike sales dataset.

Data Cleaning: Removed duplicates, handled inconsistencies, and prepared the dataset for analysis.

Data Transformation: Organized and transformed data for accurate reporting.

Pivot Tables: Created Pivot Tables to analyze customer demographics and purchasing behavior.

Data Visualization: Developed charts to highlight important trends and patterns.

Dashboard Development: Built an interactive Bike Sales Dashboard using charts, Pivot Tables, and slicers.
